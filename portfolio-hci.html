UMT Repository System Redesign (HCI)

Human-Computer Interaction Project — UI/UX Redesign of UMT Institutional Repository

About the Project

This Human-Computer Interaction (HCI) assignment involves the redesign of the UMT Institutional Repository System, originally found at umt-ir.umt.edu.my:8080. The project aims to enhance usability, aesthetics, and accessibility through structured analysis, user-centered design, and heuristic evaluation.

Project Structure

  • Introduction: Overview of the system, objectives, and identified problems.
  • Analysis & Design: Persona creation, task flow, and environment context (PACT analysis).
  • Design & Prototyping: High-fidelity prototype in Figma and design rationale.
  • Evaluation Report: Nielsen’s Heuristic Evaluation and feedback-driven refinements.

Key Problems Identified

  • Complex and outdated navigation system when accessing materials.
  • Poor visual hierarchy and typography reducing readability.
  • Absence of dark mode, causing eye strain during long sessions.

Proposed Solutions

  • Redesigned Advanced Search System with filters and suggestions.
  • Improved UI layout with consistent typography and alignment.
  • Implemented Dark/Light Mode toggle for comfort and accessibility.
