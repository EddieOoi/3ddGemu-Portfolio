ZeroWasteHub

Mobile app (Flutter & Firebase) to promote recycling, connect local recyclers, and reward sustainable actions.

About the Project

ZeroWasteHub is a community-focused mobile application built to encourage recycling and reduce waste. The app connects users with local recycling centres, schedules pick-ups, and rewards eco-friendly actions through a points system and in-app badges.

Development Overview

  • Built with Flutter (Dart) for cross-platform mobile delivery (Android & iOS).
  • Backend and real-time features implemented using Firebase (Firestore, Authentication, Cloud Functions, Storage).
  • Features include user profiles, location-based recycler directory, photo-based item submissions, pick-up scheduling, and a points & rewards system.
  • Focus on accessibility and low-bandwidth performance for broader community reach.

My Role & Contribution

I developed the full front-end UI in Flutter and integrated Firebase services for authentication, data storage, and serverless logic. Key contributions include implementing the login system, UI design, customer and admin server.

Impact & Vision

ZeroWasteHub aims to lower barriers to recycling by connecting users with local resources and rewarding sustainable behaviour. The project demonstrates how mobile tech can support environmental initiatives and community engagement.
